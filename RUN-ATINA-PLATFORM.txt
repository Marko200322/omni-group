ATINA Platform — lokacija u ovom monorepu:
  atina-platform/atina/

Prerequisites: Node.js 20.x, Docker (za Postgres + Redis).
Napomena: projekat ima engine ">=20 <21" (Node 20 LTS).

1) Baza (jednom):
   cd atina-platform/atina
   docker compose up -d postgres redis

2) Env:
   copy .env.example .env
   (uredi kredencijale: DB_*, JWT_*, Stripe, SMTP, itd.)
   Dev default: SMTP_ENABLED=false (bez SMTP warning-a i bez slanja mejlova)
   Ako testiras email: postavi SMTP_ENABLED=true i unesi validne SMTP_* vrednosti

3) Instalacija i šema:
   npm install
   npm run migrate
   npm run seed

4) Dev server:
   npm run dev
   (robust start: npm run dev:start)
   stop: npm run dev:stop
   http://localhost:3000/health
   API: http://localhost:3000/api/v1

Napomene:
- Seed admin: vidi ADMIN_EMAIL / ADMIN_PASSWORD u .env.example
- Ispravljeni npm skriptovi: migrate/seed/dev koriste npx (Windows)
- Dodat devDependency @types/pg za migrate/seed
- Uklonjeni prazni pogrešni folderi iz zipa: src\{core,...}, database\{migrations,seeds}

Pun stack u Dockeru (app + db + redis):
   cd atina-platform/atina
   docker compose up -d --build

Troubleshooting:
- Ako dobijes "EADDRINUSE :::3000", ugasi stari Node proces pa ponovo pokreni:
  PowerShell: Get-NetTCPConnection -LocalPort 3000 -State Listen | Select-Object OwningProcess
  PowerShell: Stop-Process -Id <PID> -Force
  Ili: npm run free:port
- Ako vidis SMTP warning, ostavi SMTP_ENABLED=false u dev okruzenju

Daily checklist:
1) cd atina-platform/atina
2) npm run dev:ready
3) npm run dev:start
4) npm run dev:check
5) npm run dev:restart (po potrebi)
6) npm run dev:stop (na kraju rada)

Ready checks:
- Health: http://localhost:3000/health
- API root: http://localhost:3000/api/v1
- Quick health smoke: powershell -ExecutionPolicy Bypass -File .\scripts\smoke-health.ps1
- NPM smoke health: npm run smoke:health
- NPM smoke all: npm run smoke:all (scripts/smoke-all.ps1: health, one login, /me, forge/status, workflow stats, forge-admin — formalni Atina release gate: atina-platform/atina/docs/operations/release-gate-checklist.md *Smoke tests*)
- Dev readiness check (smoke + lint): npm run dev:check
- Pre-start ready (bootstrap + lint): npm run dev:ready

Quick auth smoke test (PowerShell):
cd atina-platform/atina
powershell -ExecutionPolicy Bypass -File .\scripts\smoke-auth.ps1
- NPM smoke auth: npm run smoke:auth
