## Feature flagovi (**(F)** — **CEO sekcija D** u [`CHECKLIST-CEO-SISTEM.md`](../CHECKLIST-CEO-SISTEM.md); master red #15)

Registracija modula u [`CoreEngine.ts`](../atina-platform/atina/src/core/CoreEngine.ts) zavisi od [`config.features`](../atina-platform/atina/src/config/index.ts) (env: **`ENABLE_CRM`**, **`ENABLE_ANALYTICS`**, **`ENABLE_AUTOMATION`**, **`ENABLE_SCRAPER`** — podrazumevano `true`).

**Matrica (F) u CEO sekciji D (50 modula):** samo **Scraper** (red #8), **CRM** (#13), **Analytics** (#35). **Automation** ima **(F)** u **CEO sekciji E** (dodatni moduli); isti mehanizam i testovi ga pokrivaju zajedno sa D.

- **Globalno (mount):** [`src/tests/unit/core-engine.test.ts`](../atina-platform/atina/src/tests/unit/core-engine.test.ts) — `crm` / `analytics` / `automation` / `scraper` se ne registruju kad su flagovi `false` (uključujući CRM i Analytics pojedinačno kada je drugi uključen).
- **Workflow validacija:** [`src/tests/unit/workflow-chain.feature-flags.test.ts`](../atina-platform/atina/src/tests/unit/workflow-chain.feature-flags.test.ts) — za **crm**, **analytics**, **scraper**, **automation** proverava se da `validate()` prijavljuje `disabled by server configuration` kad je odgovarajući flag `false`, i da nema te poruke kad je `true`.

## Kriterijum „zatvoreno“ za red #13 (celokupan modul)

- [x] Za modul: sve javne rute imaju `validateQuery` / `validateBody` / `validateParams` gde treba **ili** eksplicitno opravdanje u ovom fajlu (sekcije *Globalne javne rute* i *Dokumentovani izuzeci*) / PR za nove rute — **2026-05-11:** tabela + `CoreEngine` root rute + Stripe webhook.  
- [x] Jedan **route** ili **DTO** test pokriva happy path + jedan edge (400/401/403/404) gde ima smisla — **2026-05-11:** vidi [`MASTER-WORK-LIST.md`](./MASTER-WORK-LIST.md) odjeljak **1.1** (red **#14** mikro-koraci).  
- [x] Ako modul ima **(F)** (feature flag) u matrici [`CHECKLIST-CEO-SISTEM.md`](../CHECKLIST-CEO-SISTEM.md) — **CEO sekcija D** — test ili doc kako se ponaša kad je isključen — **2026-05-11:** [`MASTER-WORK-LIST.md`](./MASTER-WORK-LIST.md) red **#15** + sekcija *Feature flagovi* iznad.
