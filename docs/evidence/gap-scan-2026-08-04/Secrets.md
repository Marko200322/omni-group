## Pipeline (conceptual)

```
KLJUCEVI-POPUNI.local.txt
    │ apply-integration-keys.ps1
    ├─► atina .env + web .env.local
    └─► deploy.config.json (partial — see gaps)

deploy.config.json
    │ deploy-from-local-secrets.ps1
    ├─► prepare-vps-prod.ps1 (base from local .env + copyKeys)
    ├─► Patch-ProdEnvFiles (deploy.config → .env.vps.prod)
    ├─► Apply-FactoryPhaseEnvFiles (M4 flags)
    └─► deploy-to-vps.ps1 → VPS .env.docker.prod
```

`apply-integration-keys` merges **only** keys in `Merge-KljuceviIntoDeployConfig` (`deploy-config-env.ps1`). Many KLJUCEVI-only keys (flags, Cursor, BrightData, etc.) never enter `deploy.config`.
